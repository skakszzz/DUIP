# 완성도 개선 작업 지시서 (실코드 반영본)

> 대상: skakszzz/DUIP (master) — Next.js 16 / Supabase / TS
> **중요:** 아래는 일반 지시입니다. 컴포넌트/파일명·줄 위치는 바뀌어 있을 수 있으니, **Claude Code가 실제 파일을 열어 패턴을 찾아 적용**하세요. 줄번호가 아니라 "이런 코드를 찾아 이렇게 바꾼다"로 기술했습니다.
> 적용 후 `npm run build` 통과 → 재배포.

작업은 4개입니다.
1. 전역 타이포 (한글 줄바꿈 + 고정폭 숫자)
2. 상태바 안전영역(safe-area) 통일 — **동산 공유캡쳐 화면은 제외**
3. 공동작업(둘이 함께 담당) 대비 — `is_shared` + '둘이 같이' UI 미리 (DB는 별도 마이그레이션)
4. (선택) 눌림 피드백 유틸

> 참고: **D-day 배지는 손대지 않습니다.** 실코드가 이미 3색 위계(당일 빨강 `#C77C6A` · D-3 이내 주황 `#E8A87C` · 그 외 초록 `#A0B88A`)로 처리돼 있어요. 그대로 둡니다.

## 1. 전역 타이포 (globals.css)
`app/globals.css`(또는 전역 스타일 진입점)의 `body`에 추가:

```css
body {
  word-break: keep-all;                  /* 한글이 어절(단어) 중간에서 안 끊김 */
  text-wrap: pretty;                     /* 마지막 줄 들쭉날쭉 완화 */
  font-variant-numeric: tabular-nums;    /* 날짜·D-day·N/M·시간 폭 고정 */
  font-feature-settings: "tnum" 1;
}
```
- 효과: 한국어 제목/본문 줄바꿈이 깔끔해지고, `3/5 완료` `D-12` 같은 숫자가 바뀔 때 폭이 안 흔들립니다.
- Pretendard가 tnum 지원. Tailwind를 쓰면 `@layer base { body { … } }` 안에 넣어도 됩니다.

## 2. 상태바 안전영역(safe-area) 통일
### 문제
화면마다 상단 여백 처리가 제각각입니다.
- 일부 화면(예: 오늘/Today 헤더)은 **상단을 px 하드코딩** — 대표 패턴: `padding: '52px 20px 12px'`, `paddingTop: 52`.
- 동산(garden) 화면은 `paddingTop: 'max(env(safe-area-inset-top), 20px)'`로 **이미 올바르게** 처리.

→ 노치 없는 기종·다이내믹 아일랜드에서 하드코딩 52px이 실제 시간/배터리 영역과 안 맞아 침범/뜸이 생깁니다.

### 해결 — 모든 화면을 env() 기준으로 통일
최상단 컨테이너/헤더의 **상단 패딩만** 아래로 교체(좌우·하단 값은 유지):

```diff
- padding: '52px 20px 12px',
+ paddingTop: 'max(env(safe-area-inset-top), 52px)',
+ paddingLeft: 20, paddingRight: 20, paddingBottom: 12,
```
```diff
- paddingTop: 52,
+ paddingTop: 'max(env(safe-area-inset-top), 52px)',
```

권장: 반복을 줄이려 globals.css에 유틸 클래스를 만들고 각 화면 최상단에 부여:
```css
.app-safe-top { padding-top: max(env(safe-area-inset-top), 52px); }
```

**찾을 대상:** `app/workspaces/[workspaceId]/**` 아래 각 탭/페이지의 최상단 헤더에서 상단을 px로 박아둔 곳 전부(today·이번달·캘린더·메모·설정 등). `52` 외 다른 상수(`44`, `56` 등)로 박힌 것도 같은 방식으로.

### ⚠️ 제외 — 동산 공유캡쳐 화면
동산 탭은 **공유용으로 화면을 캡쳐**하는 경우가 있어, 기기별 inset이 캡쳐 결과를 들쭉날쭉하게 만들면 안 됩니다. **색·여백이 캡쳐에서 일정해야 하므로, 동산의 캡쳐 대상 영역(보호수+화분이 그려지는 풀블리드 무대)은 safe-area 통일에서 제외하고 현재 상태(고정 레이아웃)를 유지**하세요.
- 단, 동산 화면이라도 **캡쳐에 안 들어가는 일반 UI 칩/버튼**(상단 연도 캡션 등)이 시간/배터리와 겹치면, 그건 캡쳐 영역 밖이므로 inset을 적용해도 됩니다. 캡쳐 프레임 안/밖을 기준으로 판단.

### (선택) 하단도 같이
탭바·FAB가 홈 인디케이터에 닿는 기종이 있으면 하단도:
`paddingBottom: 'max(env(safe-area-inset-bottom), 22px)'` — 이번 범위 밖이면 생략.

## 3. 공동작업(둘이 함께 담당) 대비
지금은 항목당 담당자 1명(`owner_user_id`). 나중에 "둘이 같이"를 붙였을 때 **자동으로 작동하도록 표시 UI를 미리** 깔아둡니다. DB 컬럼은 별도 마이그레이션으로.

### 3-1. DB 마이그레이션 (별도 실행 메모)
`items` 테이블에 boolean 추가:
```sql
-- supabase/migrations/<timestamp>_add_items_is_shared.sql
ALTER TABLE items ADD COLUMN is_shared boolean NOT NULL DEFAULT false;
```
- 의미: `is_shared = true` → 워크스페이스 두 멤버가 **함께 담당**. 이때 `owner_user_id`는 무시(또는 null 허용).
- 기존 행은 기본 false라 영향 없음.

### 3-2. 타입에 필드 추가
`Item`/`CalItem` 인터페이스(여러 뷰에 중복 정의돼 있음)에 추가, 그리고 `lib/types`에 공용 타입이 있으면 거기도:
```ts
is_shared: boolean;   // 기본 false
```
insert/select 하는 곳에서 `is_shared` 포함.

### 3-3. 담당 선택 UI — '둘이 같이' 옵션
담당자를 고르는 모든 곳(오늘 추가 시트·캘린더 추가 시트·항목 편집 모달의 `<select>` 또는 사람 칩)에서, 멤버 목록 끝에 **'둘이 같이'** 옵션 추가:

```tsx
// select 방식이면
<select
  value={isShared ? '__shared__' : ownerUserId}
  onChange={(e) => {
    if (e.target.value === '__shared__') { setIsShared(true); }
    else { setIsShared(false); setOwnerUserId(e.target.value); }
  }}
>
  {members.map((m) => (
    <option key={m.user_id} value={m.user_id}>{m.avatar} {m.display_name}</option>
  ))}
  {members.length >= 2 && <option value="__shared__">👥 둘이 같이</option>}
</select>
```
insert payload:
```ts
owner_user_id: isShared ? null : ownerUserId,
is_shared: isShared,
```
> 멤버가 1명(파트너 미초대)일 땐 '둘이 같이' 옵션을 숨깁니다(`members.length >= 2` 조건).

### 3-4. 아바타 표시 — 공용 컴포넌트
지금은 각 뷰가 `owner.display_name.charAt(0)` 단일 원형을 직접 그립니다. 공용 컴포넌트로 빼서 `is_shared`면 **두 멤버 아바타를 겹쳐** 표시:

```tsx
// components/owner-avatar.tsx
export function OwnerAvatar({
  item, members, size = 24, ring = '#FFFCF7',
}: {
  item: { is_shared?: boolean; owner_user_id: string | null };
  members: { user_id: string; display_name: string; color: string }[];
  size?: number; ring?: string;
}) {
  const dot = (m: { display_name: string; color: string }, key: number, shift: number) => (
    <div key={key} style={{
      width: size, height: size, borderRadius: 9999,
      background: m.color, color: '#fff',
      fontSize: Math.round(size * 0.42), fontWeight: 800,
      display: 'flex', alignItems: 'center', justifyContent: 'center',
      boxShadow: `0 0 0 2px ${ring}`,
      marginLeft: shift, position: 'relative', zIndex: 10 - key, flexShrink: 0,
    }}>{m.display_name.charAt(0)}</div>
  );

  if (item.is_shared) {
    const pair = members.slice(0, 2);             // 부부 = 2명
    const ov = -Math.round(size * 0.42);          // 겹침 폭
    return (
      <div style={{ display: 'inline-flex', alignItems: 'center' }}>
        {pair.map((m, i) => dot(m, i, i === 0 ? 0 : ov))}
      </div>
    );
  }
  const owner = members.find((m) => m.user_id === item.owner_user_id);
  if (!owner) return null;
  return <div style={{ display: 'inline-flex' }}>{dot(owner, 0, 0)}</div>;
}
```
각 뷰(today-view의 `Pebble`, calendar-view의 행)에서 기존 단일 아바타 div를 `<OwnerAvatar item={item} members={members} size={24}/>`(캘린더는 22)로 교체. 크기만 화면에 맞게.

> 결과: 평소엔 담당자 1명 아바타. '둘이 같이' 항목은 은·소 아바타가 살짝 겹쳐 떠서 공동 작업이 한눈에 보입니다. DB 마이그레이션 전이라도 `is_shared`가 undefined면 단일 표시로 안전하게 폴백.

## 4. (선택) 눌림 피드백
globals.css:
```css
.duip-press { transition: transform 120ms ease, opacity 120ms ease; }
.duip-press:active { transform: scale(0.96); opacity: 0.9; }
```
FAB·항목 행·주요 버튼에 `className="duip-press"`. 실코드 버튼 일부엔 이미 `transition: all 0.15s`가 있으니 중복되지 않게 확인.

## 적용 순서 & 확인
1. globals.css 타이포(1) + 유틸 클래스(2,4) 추가
2. 각 화면 상단 px 하드코딩 → `max(env(safe-area-inset-top), …)` 교체 (동산 캡쳐영역 제외)
3. `is_shared` 마이그레이션 작성(실행은 별도) + 타입/insert/select 반영
4. 담당 선택에 '둘이 같이' 옵션 + `OwnerAvatar` 공용화로 교체
5. `npm run build` → 재배포

### 체크
- [ ] 긴 한글 제목이 단어 중간에서 안 끊긴다.
- [ ] 숫자(N/M·D-day·날짜)가 바뀌어도 폭이 안 흔들린다.
- [ ] 노치/비노치/다이내믹 아일랜드 어디서도 헤더가 시간·배터리를 안 침범한다.
- [ ] 동산 **공유 캡쳐** 결과는 기존과 동일(색·여백 일정).
- [ ] 담당 선택에 '둘이 같이'가 보이고(파트너 있을 때만), 고르면 저장된다.
- [ ] '둘이 같이' 항목은 두 아바타가 겹쳐 보이고, 일반 항목은 단일 아바타다.
- [ ] D-day 배지는 기존 3색 그대로다.

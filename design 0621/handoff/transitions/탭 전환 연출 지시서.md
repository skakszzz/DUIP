# 탭 전환 연출 적용 지시서 — "페이드 + 떠오름" (확정)

> 시안: `탭 전환 연출 데모.html` · 확정 스타일 = **페이드+떠오름(rise)**, 약 0.5초.
> 목표: 탭을 옮길 때 나오던 **빈 크림화면 깜빡임**을 없애고, 새 화면이 부드럽게 "도착"하게.

## 왜 이렇게 했나 (원인)
- 탭바는 `<Link>` 로 세그먼트 라우트(`/today` `/memos` `/calendar` `/garden`)를 오갑니다.
- 그 사이 각 탭의 `loading.tsx`(전체 크림 빈화면)가 Suspense 폴백으로 잠깐 떠서 **깜빡**입니다.
- 해결은 두 가지를 함께:
  1. **진입 애니메이션** — `template.tsx` 로 라우트 이동마다 콘텐츠가 페이드+떠오름으로 도착.
  2. **빈 폴백 제거** — `loading.tsx` 를 빈화면 대신 **스켈레톤**으로 교체.

`template.tsx` 는 `layout.tsx` 와 달리 **라우트 이동마다 다시 마운트**되므로 진입 연출에 딱 맞습니다. 탭바는 `layout.tsx` 에 그대로 두면 안 깜빡입니다.

---

## 적용 (드롭인 3종)

### 1) 진입 애니메이션 — `template.tsx`
- 파일: `handoff/transitions/template.tsx`
- 배치: **`app/workspaces/[workspaceId]/template.tsx`** (탭 세그먼트들의 공통 부모, 단 하나)
- 이게 있으면 홈↔메모↔캘린더↔동산 이동마다 children 이 0.5초 rise 로 들어옵니다.

### 2) 스켈레톤 컴포넌트 — `tab-skeleton.tsx`
- 파일: `handoff/transitions/tab-skeleton.tsx`
- 배치: **`components/tab-skeleton.tsx`**
- `variant`(home/memo/calendar/garden)별로 골격 모양이 다릅니다.

### 3) 각 탭 `loading.tsx` 교체 (4개)
- 참고: `handoff/transitions/loading.각탭.tsx` (4개 코드가 한 파일에 모여 있음)
- 각각 해당 경로의 **기존 빈 `loading.tsx` 를 대체**:

```
app/workspaces/[workspaceId]/today/loading.tsx     → variant="home"
app/workspaces/[workspaceId]/memos/loading.tsx     → variant="memo"
app/workspaces/[workspaceId]/calendar/loading.tsx  → variant="calendar"
app/workspaces/[workspaceId]/garden/loading.tsx    → variant="garden"
```

각 파일 내용(예: 홈):
```tsx
import TabSkeleton from '@/components/tab-skeleton';
export default function Loading() {
  return <TabSkeleton variant="home" />;
}
```

> 기존에 공통 `loading.tsx`(잎 흔들림 + "불러오는 중…")를 쓰고 있었다면 그건 **상위 진입/새로고침용**으로 남겨도 되고, 탭 세그먼트만 위 스켈레톤으로 바꾸면 됩니다.

---

## 동작 정리
- **탭 전환(데이터 빠름/캐시 따뜻):** template 재마운트 → 콘텐츠가 곧장 rise 로 도착. (빈화면 0)
- **탭 전환(데이터 지연):** 빈화면 대신 **스켈레톤이 rise 로** 먼저 뜨고 → 콘텐츠로 교체.
- **접근성:** `prefers-reduced-motion: reduce` 면 떠오름 대신 짧은 페이드만.

## 건드리지 않는 것
- 화면 컴포넌트(HomeView/MemosView/CalendarView/GardenView) **수정 없음**.
- 탭바(`components/tab-bar.tsx`) **수정 없음** — `layout.tsx` 에 있으면 그대로 머뭅니다.
  - ⚠️ 만약 탭바가 각 `page` 안에서 렌더되고 있다면, `layout.tsx` 로 올려야 안 깜빡입니다. (현재 구조 확인 요망)

## 확인 체크
- [ ] 네 탭을 빠르게 왕복 → 빈 크림화면이 안 보인다.
- [ ] 새 화면이 살짝 아래에서 위로 떠오르며 들어온다(≈0.5s).
- [ ] 느린 네트워크(크롬 DevTools Slow 3G)에서 빈화면 대신 스켈레톤이 뜬다.
- [ ] 시스템 "동작 줄이기" 켜면 떠오름 없이 페이드만.
